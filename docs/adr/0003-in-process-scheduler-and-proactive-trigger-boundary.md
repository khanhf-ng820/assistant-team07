# In-Process Scheduler and Proactive Trigger Boundary

Status: accepted

CARENTA runs background checks (evening check-in reminders and daily habit analysis) and unified assistant orchestration inside the single FastAPI process—combining an opt-in, clock-injectable `asyncio` scheduler managed by FastAPI `lifespan` with idempotent HTTP trigger endpoints (`POST /api/v1/jobs/{job_name}/run` for one authenticated Student Identity and `POST /api/v1/internal/jobs/{job_name}/run` guarded by constant-time `X-Scheduler-Secret` for external cron pings)—rather than introducing a separate worker/broker service, `APScheduler`, or remote FCM/APNs push dispatch. Keeping orchestration and scheduling in-process honors the single-service December architecture while the idempotent HTTP trigger endpoints ensure scheduled checks survive Render Free's 15-minute idle spin-down and remain deterministically testable without real wall-clock waits. Backend evaluation emits read-only Proactive Triggers reconciled locally by mobile via `expo-notifications` and in-app banners, and behind internal `InsightProviderProtocol` and `HabitAnalyzerProtocol` seams so Phase 3 orchestration ships independently of unmerged teammate PRs while preserving the invariant that no background job or trigger ever writes a financial transaction automatically.
